# Project Scope Rule

GTV Digital World is a finite single-release indie web game.

The project will be considered complete after Version 1.0 is released.

After Version 1.0, allowed changes are limited to:

- Bug fixes
- Typographical corrections
- Performance improvements
- Accessibility improvements
- Minor visual polishing
- Broken-link or asset corrections

The following are outside the project scope after release:

- New locations
- New story chapters
- New missions
- New game modes
- Multiplayer
- Backend accounts
- Continuous content updates
- Seasonal events
- Downloadable content
